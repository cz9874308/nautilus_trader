## 学习建议

### 对于完全初学者

1.  **慢慢来**：不要匆忙完成教程。在继续之前确保您理解每个概念。

2.  **练习**：每课后，尝试修改代码示例。实验并看看会发生什么！

3.  **提问**：如果有什么不明白的，请复习之前的课程或查看 [FAQ](../faq.md)。

4.  **使用示例**：这些教程中的代码基于真实示例。查看 [examples 目录](https://github.com/nautechsystems/nautilus_trader/tree/develop/examples) 了解更多。

### 对于有经验的程序员

如果您已经熟悉 Python 和交易概念：

-   如果您理解算法交易，可以跳过第 1 课
-   第 2 课提供了 NautilusTrader 特定概念的快速参考
-   专注于第 3-7 课进行实践

## 接下来是什么？

完成所有教程后，您将准备好：

-   编写您自己的交易策略
-   在历史数据上回测策略
-   将策略部署到实盘市场
-   探索高级功能

### 推荐的下一步

1.  **探索概念**：阅读[概念指南](../../concepts/index.md)以获得更深入的理解

3.  **阅读 API 参考**：在编码时使用 [API 参考](../../api_reference/index.md) 作为参考

4.  **加入社区**：在 [Discord](https://discord.gg/NautilusTrader) 上与其他用户联系
