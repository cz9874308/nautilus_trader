## 第 1 步：理解我们将构建什么

我们将创建一个**超级简单的策略**，它：

1.  监控价格 K 线（K 线数据）

2.  在第 3 根 K 线上下一个卖单

3.  在第 6 根 K 线上下一个买单（以平仓）

这是故意简化的，这样您就可以专注于理解一切是如何工作的！

## 第 3 步：编写策略

创建 `strategy.py`：

```python
# 策略文件

import datetime as dt

from nautilus_trader.common.enums import LogColor
from nautilus_trader.core.datetime import unix_nanos_to_dt
from nautilus_trader.model.data import Bar
from nautilus_trader.model.data import BarType
from nautilus_trader.model.enums import OrderSide
from nautilus_trader.model.enums import TimeInForce
from nautilus_trader.model.objects import Quantity
from nautilus_trader.trading.strategy import Strategy


class MyFirstStrategy(Strategy):
    """
    我的第一个交易策略！

    这个策略：
    - 监控价格 K 线
    - 在第 3 根 K 线上卖出
    - 在第 6 根 K 线上买入（平仓）
    """

    def __init__(self, input_bartype: BarType):
        """
        初始化策略。

        Args:
            input_bartype: 要监控的 K 线类型（例如，1 分钟 K 线）
        """
        # 始终首先调用 super().__init__()！
        super().__init__()

        # 存储我们要监控的 K 线类型
        self.input_bartype = input_bartype

        # 从 K 线类型获取工具 ID
        self.instrument_id = input_bartype.instrument_id

        # 跟踪我们处理了多少根 K 线
        self.bars_processed = 0

        # 跟踪我们是否已下订单
        self.order_placed = False

    def on_start(self):
        """
        策略启动时调用。

        这是您设置策略的地方：
        - 订阅数据源
        - 初始化指标
        - 设置定时器
        """
        self.log.info("🚀 My first strategy has started!", color=LogColor.GREEN)

        # 订阅 K 线数据
        # 这告诉系统："给我发送这种类型的 K 线更新"
        self.subscribe_bars(self.input_bartype)

        self.log.info(f"📊 Subscribed to: {self.input_bartype}")

    def on_bar(self, bar: Bar):
        """
        每次收到新的 K 线时调用。

        Args:
            bar: K 线数据（包含开盘、最高、最低、收盘、成交量）
        """
        # 增加计数器
        self.bars_processed += 1

        # 记录 K 线信息
        bar_time = unix_nanos_to_dt(bar.ts_event)
        self.log.info(
            f"📈 Bar #{self.bars_processed} | "
            f"Time: {bar_time:%Y-%m-%d %H:%M:%S} | "
            f"Close: {bar.close}",
            color=LogColor.BLUE,
        )

        # 策略逻辑
        # ====================

        # 在第 3 根 K 线：下一个卖单
        if not self.order_placed and self.bars_processed == 3:
            self.log.info("🎯 Time to SELL! (3rd bar)", color=LogColor.YELLOW)

            # 创建市价单（立即以最佳价格执行）
            order = self.order_factory.market(
                instrument_id=self.instrument_id,  # 交易什么
                order_side=OrderSide.SELL,         # 卖出（做空）
                quantity=Quantity.from_int(1),     # 交易多少（1 单位）
                time_in_force=TimeInForce.GTC,     # 直到取消
            )

            # 将订单提交到系统
            self.submit_order(order)
            self.order_placed = True

            self.log.info(
                f"✅ SELL order placed at price: {bar.close}",
                color=LogColor.GREEN,
            )

        # 在第 6 根 K 线：下一个买单（以平空头持仓）
        elif self.order_placed and self.bars_processed == 6:
            self.log.info("🎯 Time to BUY! (6th bar - closing position)", color=LogColor.YELLOW)

            # 创建买单（平空头）
            order = self.order_factory.market(
                instrument_id=self.instrument_id,
                order_side=OrderSide.BUY,          # 买入（平空）
                quantity=Quantity.from_int(1),      # 相同数量
                time_in_force=TimeInForce.GTC,
            )

            self.submit_order(order)

            self.log.info(
                f"✅ BUY order placed at price: {bar.close}",
                color=LogColor.RED,
            )

    def on_stop(self):
        """
        策略停止时调用。

        这是您清理的地方：
        - 取消未完成的订单
        - 平仓
        - 保存状态
        """
        self.log.info("🛑 Strategy stopped", color=LogColor.MAGENTA)
        self.log.info(f"📊 Total bars processed: {self.bars_processed}")
```

### 代码解释

让我们分解关键部分：

#### 1. **类定义**

```python
class MyFirstStrategy(Strategy):
```

-   我们继承自 `Strategy` - 这给了我们所有交易能力

#### 2. **`__init__` 方法**

```python
def __init__(self, input_bartype: BarType):
    super().__init__()
```

-   `super().__init__()` - **始终首先调用这个！**它初始化策略

-   我们存储 K 线类型，这样我们就知道要订阅什么数据

#### 3. **`on_start` 方法**

```python
def on_start(self):
    self.subscribe_bars(self.input_bartype)
```

-   策略启动时调用一次

-   `subscribe_bars()` 告诉系统向我们发送 K 线更新

#### 4. **`on_bar` 方法**

```python
def on_bar(self, bar: Bar):
```

-   每次收到新 K 线时调用

-   这就是您的交易逻辑所在！

#### 5. **创建订单**

```python
order = self.order_factory.market(
    instrument_id=self.instrument_id,
    order_side=OrderSide.SELL,
    quantity=Quantity.from_int(1),
    time_in_force=TimeInForce.GTC,
)
self.submit_order(order)
```

-   `order_factory.market()` - 创建市价单（立即执行）

-   `OrderSide.SELL` - 我们想卖出（做空）

-   `Quantity.from_int(1)` - 我们想交易 1 单位

-   `submit_order()` - 将订单发送到系统

## 第 4 步：创建回测

创建 `run_backtest.py`：

```python
# 运行回测文件

from datetime import UTC, datetime
from decimal import Decimal

from strategy import MyFirstStrategy

from nautilus_trader.backtest.config import BacktestEngineConfig
from nautilus_trader.backtest.engine import BacktestEngine
from nautilus_trader.config import LoggingConfig
from nautilus_trader.core.datetime import dt_to_unix_nanos
from nautilus_trader.data.config import DataEngineConfig
from nautilus_trader.model import Bar, BarType, TraderId
from nautilus_trader.model.currencies import USD
from nautilus_trader.model.enums import AccountType, OmsType
from nautilus_trader.model.identifiers import Venue
from nautilus_trader.model.objects import Money, Quantity
from nautilus_trader.test_kit.providers import TestInstrumentProvider

# 常量
NANOSECONDS_IN_SECOND = 1_000_000_000


def generate_artificial_bars(instrument, bar_type):
    """
    生成一些用于测试的假价格数据。

    在真实场景中，您会从文件或数据库加载数据。
    """
    bars = []

    # 起始价格
    base_price = 1.10000
    price_increment = 0.00010  # 每根 K 线 10 个点

    # 起始时间
    start_time = dt_to_unix_nanos(
        datetime(2024, 2, 1, hour=0, minute=0, second=0, tzinfo=UTC)
    )
    time_increment = 60 * NANOSECONDS_IN_SECOND  # 每根 K 线 1 分钟

    # 生成 10 根 K 线
    for i in range(10):
        current_price = base_price + (i * price_increment)
        bar_time = start_time + (i * time_increment)

        bar = Bar(
            bar_type=bar_type,
            open=instrument.make_price(current_price),
            high=instrument.make_price(current_price + 0.00005),
            low=instrument.make_price(current_price - 0.00005),
            close=instrument.make_price(current_price),
            volume=Quantity.from_int(1000),
            ts_event=bar_time,
            ts_init=bar_time,
        )
        bars.append(bar)

    return bars


def run_backtest():
    """
    运行回测的主函数。
    """
    print("=" * 60)
    print("🚀 启动我的第一个回测！")
    print("=" * 60)

    # 第 1 步：配置回测引擎
    engine_config = BacktestEngineConfig(
        trader_id=TraderId("MY_FIRST_TRADER-001"),

        # 数据引擎配置
        data_engine=DataEngineConfig(
            time_bars_interval_type="left-open",
            time_bars_timestamp_on_close=True,
            time_bars_skip_first_non_full_bar=False,
            validate_data_sequence=True,
        ),

        # 日志配置
        logging=LoggingConfig(
            log_level="INFO",  # 设置为 "DEBUG" 查看更多细节
        ),
    )

    # 创建引擎
    engine = BacktestEngine(config=engine_config)

    # 第 2 步：添加交易场所（交易所）
    VENUE_NAME = "XCME"  # 模拟交易所

    engine.add_venue(
        venue=Venue(VENUE_NAME),
        oms_type=OmsType.NETTING,           # 净持仓
        account_type=AccountType.MARGIN,    # 保证金账户
        starting_balances=[Money(1_000_000, USD)],  # 从 100 万美元开始
        base_currency=USD,
        default_leverage=Decimal(1),         # 无杠杆
    )

    print(f"✅ Added venue: {VENUE_NAME}")

    # 第 3 步：创建并添加工具（我们要交易的东西）
    EURUSD_FUTURE = TestInstrumentProvider.eurusd_future(
        expiry_year=2024,
        expiry_month=3,
        venue_name=VENUE_NAME,
    )
    engine.add_instrument(EURUSD_FUTURE)

    print(f"✅ Added instrument: {EURUSD_FUTURE.id}")

    # 第 4 步：准备数据
    EURUSD_1MIN_BARTYPE = BarType.from_str(
        f"{EURUSD_FUTURE.id}-1-MINUTE-LAST-EXTERNAL"
    )

    # 生成人工 K 线
    bars = generate_artificial_bars(EURUSD_FUTURE, EURUSD_1MIN_BARTYPE)
    engine.add_data(bars)

    print(f"✅ Added {len(bars)} bars of data")

    # 第 5 步：创建并添加策略
    strategy = MyFirstStrategy(input_bartype=EURUSD_1MIN_BARTYPE)
    engine.add_strategy(strategy)

    print("✅ Strategy added")
    print("-" * 60)

    # 第 6 步：运行回测！
    print("▶️  运行回测...")
    engine.run()

    print("-" * 60)
    print("✅ 回测完成！")

    # 第 7 步：清理
    engine.dispose()


if __name__ == "__main__":
    run_backtest()
```

### 理解输出

1.  **策略启动** - 您的 `on_start()` 方法被调用

2.  **收到 K 线** - 每根 K 线触发 `on_bar()`

3.  **订单已下** - 在第 3 根 K 线（卖出）和第 6 根 K 线（买入）

4.  **策略停止** - 您的 `on_stop()` 方法被调用

## 常见问题

### 问：为什么我们先卖出，然后买入？

答：这创建了一个**空头持仓**（押注价格会下跌）。然后我们通过买入来平仓。在真实策略中，如果您认为价格会上涨，您可能会先买入（做多）。

### 问：什么是 `BarType`？

答：`BarType` 指定您想要的 K 线类型：工具、时间框架（1 分钟、5 分钟等）和价格类型（LAST、BID、ASK 等）。

### 问：为什么使用人工数据？

答：为了学习！真实数据需要设置并且可能很大。人工数据让您专注于学习代码。

## 📌 核心要点总结

1. **策略继承自 `Strategy` 类，实现生命周期方法**
2. **`on_start()` 用于初始化，`on_stop()` 用于清理**
3. **必须订阅数据才能接收市场更新**
4. **使用 `order_factory` 创建订单，使用 `submit_order()` 提交**
5. **回测使用 `BacktestEngine`，实盘使用 `TradingNode`**
6. **策略代码在回测和实盘中完全相同**
