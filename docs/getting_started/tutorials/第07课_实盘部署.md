## ⚠️ 重要警告

### 真实资金风险

**实盘交易涉及真实的金融风险。**

-   从**模拟交易**（模拟账户）开始

-   实盘时使用**小额资金**

-   首先在回测中**充分测试**

-   首次实盘时**密切监控**

### 先进行模拟交易

大多数交易所提供**模拟交易**或**测试网**账户：

-   **Binance 测试网** - 免费测试账户

-   **Bybit 测试网** - 免费测试账户

-   **Interactive Brokers 模拟交易** - 免费模拟账户

**在使用真实资金之前，始终使用模拟交易进行测试！**

## 第 1 步：准备您的策略

### 检查清单

在实盘之前，确保：

-   ✅ 策略已经过充分回测

-   ✅ 策略优雅地处理错误

-   ✅ 风险限制已配置

-   ✅ 日志已设置用于监控

-   ✅ 策略代码与回测相同（无需更改！）

### 代码审查

审查您的策略：

```python
class MyLiveStrategy(Strategy):
    def __init__(self):
        super().__init__()
        # ✅ 初始化所有变量
        self.position_size = 0
        self.last_price = None

    def on_start(self):
        # ✅ 订阅数据
        self.subscribe_bars(self.bar_type)

        # ✅ 设置错误处理
        self.log.info("Strategy starting...")

    def on_bar(self, bar: Bar):
        # ✅ 检查错误
        if bar.close <= 0:
            self.log.error("Invalid price!")
            return

        # ✅ 您的交易逻辑
        # （与回测相同！）
        pass

    def on_order_rejected(self, event: OrderRejected):
        # ✅ 处理拒绝
        self.log.warning(f"Order rejected: {event.reason}")
```

## 第 2 步：交易所设置

### 获取 API 密钥

1.  在交易所**创建账户**

2.  在账户设置中**启用 API 访问**

3.  **生成 API 密钥**（API Key + Secret Key）

4.  **设置权限**（数据只读，执行交易）

5.  **限制 IP 地址**（为了安全）

### 安全最佳实践

```python
# ❌ 永远不要这样做
api_key = "your_key_here"  # 硬编码在代码中

# ✅ 这样做
import os
api_key = os.getenv("BINANCE_API_KEY")  # 从环境变量
```

**安全存储 API 密钥：**

-   使用环境变量

-   使用密钥管理器

-   永远不要将密钥提交到 git

## 第 3 步：配置

### 基本实盘配置

```python
from nautilus_trader.config import TradingNodeConfig
from nautilus_trader.live.node import TradingNode

# 配置交易节点
config = TradingNodeConfig(
    trader_id=TraderId("MY_TRADER-001"),

    # 数据客户端配置
    data_clients={
        "BINANCE": BinanceDataClientConfig(
            api_key=os.getenv("BINANCE_API_KEY"),
            api_secret=os.getenv("BINANCE_API_SECRET"),
            base_url_http="https://testnet.binance.vision",  # 测试网
            base_url_ws="wss://testnet.binance.vision/ws",   # 测试网
        ),
    },

    # 执行客户端配置
    exec_clients={
        "BINANCE": BinanceExecClientConfig(
            api_key=os.getenv("BINANCE_API_KEY"),
            api_secret=os.getenv("BINANCE_API_SECRET"),
            base_url_http="https://testnet.binance.vision",  # 测试网
            base_url_ws="wss://testnet.binance.vision/ws",   # 测试网
        ),
    },

    # 风险引擎配置
    risk_engine=LiveRiskEngineConfig(
        bypass=False,  # 启用风险检查！
        max_order_submit_rate="100/00:00:01",  # 每秒最多 100 个订单
        max_notional_per_order={"USD": 10000},  # 每单最多 1 万美元
    ),

    # 日志
    logging=LoggingConfig(
        log_level="INFO",
        log_to_file=True,  # 将日志保存到文件
    ),
)

# 创建并配置节点
node = TradingNode(config=config)

# 添加您的策略
strategy = MyLiveStrategy()
node.trader.add_strategy(strategy)

# 添加工具
# （通常从交易所加载）

# 启动节点
node.run()
```

## 第 4 步：运行实盘

### 启动交易节点

```python
if __name__ == "__main__":
    # 创建节点
    node = TradingNode(config=config)

    try:
        # 开始交易
        node.run()
    except KeyboardInterrupt:
        # Ctrl+C 时优雅关闭
        print("Shutting down...")
        node.stop()
    finally:
        # 清理
        node.dispose()
```

### 监控

当您的策略运行时，监控：

1.  **日志** - 检查错误或警告

2.  **持仓** - 验证持仓是否符合预期

3.  **订单** - 检查订单执行

4.  **账户余额** - 监控资金

### 监控脚本示例

```python
import time

def monitor_strategy(node):
    """监控策略表现"""
    while node.is_running():
        # 获取投资组合
        portfolio = node.trader.portfolio

        # 获取账户
        account = portfolio.account(account_id)

        # 打印状态
        print(f"Balance: {account.balance_total(USD)}")
        print(f"Positions: {len(list(portfolio.positions()))}")
        print(f"Open orders: {len(list(node.cache.orders_open()))}")

        time.sleep(5)  # 每 5 秒更新一次
```

## 第 5 步：与回测的差异

### 关键差异

| 方面         | 回测           | 实盘交易           |
| :----------- | :------------- | :----------------- |
| **数据**     | 历史（一次性） | 实时（流式）       |
| **执行**     | 即时（模拟）   | 真实（有延迟）     |
| **滑点**     | 可配置         | 真实（变化）       |
| **费用**     | 可配置         | 真实（交易所费率） |
| **网络问题** | 无             | 可能断开连接       |
| **错误**     | 可以重启       | 必须优雅处理       |

### 处理现实世界的问题

#### 网络断开

```python
def on_disconnected(self):
    """连接丢失时调用"""
    self.log.warning("Connection lost! Pausing strategy...")
    # 取消未完成的订单
    self.cancel_all_orders(self.instrument_id)
    # 等待重新连接
```

#### 交易所错误

```python
def on_order_rejected(self, event: OrderRejected):
    """处理交易所拒绝"""
    if "insufficient" in event.reason.lower():
        self.log.error("Insufficient balance!")
        # 停止交易
        self.stop()
    elif "rate limit" in event.reason.lower():
        self.log.warning("Rate limit hit, waiting...")
        # 实现退避
        time.sleep(60)
```

## 常见问题和解决方案

### 问题 1：连接超时

**症状**：无法连接到交易所

**解决方案**:

-   检查互联网连接

-   验证 API 密钥是否正确

-   检查防火墙设置

-   先尝试测试网

### 问题 2：订单被拒绝

**症状**：订单不断被拒绝

**解决方案**:

-   检查账户余额

-   验证订单大小限制

-   检查工具是否可交易

-   审查风险引擎设置

### 问题 3：数据缺失

**症状**：策略未收到市场数据

**解决方案**:

-   验证数据订阅

-   检查 WebSocket 连接

-   审查交易所 API 状态
